# 자기소개 프로젝트

## 📌 프로젝트 소개
Git과 GitHub 협업 워크플로우를 학습하기 위한 프로젝트입니다.  
브랜치를 나누고 Pull Request를 통해 협업 흐름을 경험하는 것이 목적입니다.

---

## 🛠️ 작업 계획

- feature/readme : README 작성
- feature/about : 자기소개 작성
- feature/skills : 관심 기술 작성
- feature/goals : 온보딩 목표 작성

---

## 🔄 진행 순서

1. README 작성 및 계획 정리
2. feature/about 브랜치 생성 후 자기소개 작성
3. feature/skills 브랜치 생성 후 기술 스택 작성
4. feature/goals 브랜치 생성 후 목표 작성
5. 각 브랜치별 Pull Request 생성
6. Self Review 진행
7. main 브랜치에 Merge
